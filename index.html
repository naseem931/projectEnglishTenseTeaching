Publish to Your GitHub Pages

This app is 100% static, modern JavaScript with zero dependencies and works directly on GitHub Pages!

1
Create a new GitHub repository:

Go to github.com/new and name it (e.g. tenseflow or english-tenses). Choose Public.

2
Connect and push your code:

Run these commands in this directory in PowerShell or Terminal:

git init
git add .
git commit -m "Initial commit of English Tenses App"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
3
Enable GitHub Pages in Repo Settings:

Go to Settings → Pages in your GitHub repository:

  • Source: Select Deploy from a branch
  • Branch: Select main and folder / (root)
  • Click Save

Your app will be live at: https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/

Link saved to your browser!
